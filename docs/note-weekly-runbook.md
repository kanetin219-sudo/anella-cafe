## 2. 使ってよい事実

- 和裁士歴 **18年**（19年と書かない。プロモーション全体で18年に統一）
- 800着以上の着物に向き合ってきた
- 講座は **6ヶ月**
- **ミシンは使わない。針と糸だけ**
- 講義は動画配信、LINEで質問、**添削会**あり
- 修了時に認定。さらに学ぶ**認定コース**もある
- 受講料は**Web非公開。お電話の個別相談（無料）でお伝えする**
- 受講は**審査制**（難しい試験ではない）
- その場で決めなくてよい。家族と相談可
- 受講生は**50〜70代が中心**、40代も。**海外在住**の方もいる
- 洋裁も和裁も未経験の方が多い
- 先生の原点：和裁の中でも「**洗い張り**」（着物をほどいて洗い、また仕立て直す）が好きだった。そこに「仕立て直してまで、もう一度着たい」という依頼主の思いがある。その気持ちは着物を着ない人にもあるのでは、と考えて着物リメイクを始めた。最初は「洋服は作れない」と思い小物を作っていたが生地が多く残り、着物がもったいないと感じてドレスを作りSNSに投稿。50代の方から依頼を受け、成人式の振袖をドレスに仕立てて渡すと大変喜ばれた

## 3. 書いてはいけないこと

- **「簡単」「誰でもできる」「すぐできる」「失敗しない」** などの根拠のない断定
- **収入・売上の保証**（「仕事になります」「稼げます」）。実例は「オーダーを受けた」「委託販売をしている」まで
- **ミシンだと生地が傷む／縫い跡が残る／針穴が目立つ** ← 松田先生の確認が取れていない。確認が取れるまで書かない
- 先生の**未確認の苦労話**（着物が捨てられる現実に苦しんだ、子育てで時間がなかった、依頼主が泣いた、何度も諦めかけた、挫折した）
- **受講生の実名**（インタビュー動画に名前テロップがないため、文中でも名前を出さない。「受講生さん」と書く）
- 競合スクール名の名指し

## 8. note エディタの操作（重要）

noteのエディタはマークダウン記法が効かない。改行も同一段落になる。以下の方法で入れる。

### 本文を入れる
1. `https://note.com/notes/new` を開く
2. タイトル欄（textarea）をクリックしてタイトルを入力
3. **本文エリア**をクリック（見出し画像を設定済みなら画面座標 y≒600 付近。クリック後 `document.activeElement.getAttribute('contenteditable')` が `true` であることを必ず確認する。`TEXTAREA` ならタイトル欄なので押し直す）
4. `cmd+a` → `Delete` で空にする（`execCommand('delete')` では消えない）
5. JSでHTMLを貼り付ける：

```js
const el=document.querySelector('[contenteditable="true"]');el.focus();
const dt=new DataTransfer();
dt.setData('text/html', html);   // <p> <h2> <ul><li> <blockquote> が使える
dt.setData('text/plain','');
el.dispatchEvent(new ClipboardEvent('paste',{clipboardData:dt,bubbles:true,cancelable:true}));
```

### 見出し画像を入れる
ネイティブのファイル選択は開かない。**ドロップイベントで入れる。**

```js
// スクロールを先頭に戻してから
const btn=[...document.querySelectorAll('button')].find(b=>{
  const r=b.getBoundingClientRect();
  return r.width>=36&&r.width<=48&&r.height>=36&&r.height<=48&&r.top>50&&r.top<300
    &&!(b.getAttribute('aria-label')||b.innerText||'').trim();});
const file=new File([await (await fetch(IMG_URL)).blob()],'t.jpg',{type:'image/jpeg'});
let n=btn;for(let i=0;i<5&&n;i++){const dt=new DataTransfer();dt.items.add(file);
  for(const t of ['dragenter','dragover','drop'])
    n.dispatchEvent(new DragEvent(t,{dataTransfer:dt,bubbles:true,cancelable:true}));
  n=n.parentElement;}
```
→ トリミングのダイアログが出るので「保存」を押す（1568×666換算で座標 (1042, 574)）

### 本文に画像を入れる
入れたい段落の末尾にキャレットを置いてから、File を paste する。

```js
const p=[...el.children].find(n=>n.innerText.includes('アンカーにする文言'));
const r=document.createRange();r.selectNodeContents(p);r.collapse(false);
const s=getSelection();s.removeAllRanges();s.addRange(r);
// 上と同じく File を DataTransfer に入れて paste イベント
```
アップロード完了まで7秒ほど待つ。

### YouTubeを埋め込む
HTMLで貼ると素のテキストになる。**URLだけの段落を選択して削除し、text/plain で貼り直す**と埋め込みになる。

```js
const yp=[...el.children].find(n=>n.innerText.includes('youtu.be'));
const r2=document.createRange();r2.selectNodeContents(yp);
getSelection().removeAllRanges();getSelection().addRange(r2);
document.execCommand('delete');
const d2=new DataTransfer();d2.setData('text/plain','https://youtu.be/RG7cWoqWsiE');
el.dispatchEvent(new ClipboardEvent('paste',{clipboardData:d2,bubbles:true,cancelable:true}));
```
5秒待って `el.querySelectorAll('iframe').length` が1以上になることを確認。
